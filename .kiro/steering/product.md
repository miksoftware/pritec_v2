# Pritec v2.0 - Sistema de Peritajes

Vehicle inspection/appraisal management system (Sistema de Peritajes) for automotive assessments.

## Core Features
- Multi-step vehicle expertise/inspection workflow (12 steps)
- Client management (CRUD with soft delete)
- Vehicle type configuration with sections and pieces
- User authentication and session management
- PDF report generation for completed inspections
- Dashboard with statistics

## Domain Context
- "Peritaje" / "Expertise" = Vehicle inspection/appraisal
- "Piezas" = Vehicle parts/pieces
- "Secciones" = Vehicle sections (body areas)
- Primary language: Spanish (Mexico)
- Timezone: America/Mexico_City

## User Roles
- Admin users manage system configuration
- Regular users perform vehicle inspections
